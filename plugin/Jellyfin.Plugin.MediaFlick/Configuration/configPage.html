Curated collections

Optional lists you define yourself. Each entry is mirrored into a Jellyfin BoxSet like the TMDB collections above (requires the native collections setting), and MediaFlick clients show which entries are missing from your library so they can be requested. Fill in TMDB movie ids directly, or point at an MDBList movie, series, or mixed list. Your MDBList key resolves the list without leaving the server.

Media rating providers

These optional administrator credentials are encrypted at rest and are never returned to Media Flick clients. MDBList is a server fallback only when a client has no valid local MDBList key. TMDB is stored for future features and is not used for rating requests.
