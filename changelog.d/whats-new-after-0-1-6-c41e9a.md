### Added

- After signing in, a device updated from 0.1.6 shows a one-time What's new. It leads with what MediaFlick's own interface offers that Jellyfin Web does not: with MediaFlick Companion, Discover and requests through Seerr, upcoming releases from Sonarr and Radarr, MDBList ratings, TMDB movie franchises, and My Collections built from templates or public MDBList lists with your own poster; built in, instant search, spoiler protection, Letterboxd, Home shelves, and trailers and previews. It then explains why the app asked to sign in again, MPC-HC's removal, the Jellyfin versions MediaFlick and MediaFlick Companion need, and music, audiobooks and books. Entries link to their page or settings, and a Companion feature links to its page only when the server's Companion offers it. New installs and later updates never show it.
- Under the Companion features, What's new says whether the server has MediaFlick Companion. A Jellyfin administrator whose server runs Jellyfin 12.0.0 or newer and has no Companion is offered it, with a link to the install guide on flick.media; anyone else on such a server reads that their administrator can add it. On an older server it only says the Companion needs Jellyfin 12.0.0. Settings → MediaFlick Companion links to the same guide whenever a server of Jellyfin 12.0.0 or newer has no Companion, and on an older server says the Companion needs Jellyfin 12.0.0.
