### Added

- After signing in, a device updated from 0.1.6 shows a one-time What's new: MediaFlick's own interface instead of Jellyfin Web, why it asked to sign in again, the server dashboard in the browser, MPC-HC's removal, the Jellyfin versions MediaFlick and MediaFlick Companion need, and music, audiobooks and books. Each entry links to its settings page. New installs and later updates never show it.
- A Jellyfin administrator whose server runs Jellyfin 12.0.0 or newer and has no MediaFlick Companion is offered it in What's new, with a link to the install guide on flick.media. Settings → MediaFlick Companion links to the same guide whenever such a server has no Companion. On an older server neither offers an install; both say the Companion needs Jellyfin 12.0.0.
