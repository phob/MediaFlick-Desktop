### Changed

- Favorites has one name and a heart icon everywhere: the Favorites page, the Home shelf, library filters, cards, the billboard and the detail page. "My List" is gone.
- Watched toggles on cards, detail pages and episodes now read "Mark watched" or "Mark unwatched" and use a check mark.
- The release calendar is called Releases everywhere, including the Home shelf, the page heading and the Startup destination option.
- The settings Reset button is now "Restore defaults".
- The sign-in screen links to "Player and app settings", and Settings offers "Back to sign in" while you are signed out.
- Settings help for MediaFlick Companion, collections, artwork and backdrop intensity, and library filters now says what each setting does and who to ask when a server feature is missing.
- Countdown seconds can only be changed when Next episode is set to Ask with countdown.

### Fixed

- A disabled Save button no longer looks clickable.
- Preview cards for titles without an age rating no longer start their details with a stray slash.
