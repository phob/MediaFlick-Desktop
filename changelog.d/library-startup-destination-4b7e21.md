### Added

- Settings → Viewing → Startup destination lists every library under its Jellyfin name, so the app can open on any library.

### Changed

- An earlier Movies or Series startup choice now opens your first Movies or TV shows library, or Home if you have none. The choice is kept until you pick a different startup destination. If the app has not read your library list yet, for example right after you sign in, it opens Home that one time.
- If your startup library is removed from the server, the app opens Home instead, and opens the library again if the server lists it again.
