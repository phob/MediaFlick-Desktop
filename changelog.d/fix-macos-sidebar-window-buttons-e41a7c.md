### Fixed

- macOS: the window now has its close, minimize and zoom buttons. They were missing from every macOS build. Close quits MediaFlick the way Cmd+Q does, or minimizes the window if Close behavior is set to Minimize window, and the window still reopens at its saved size and position.
- The side menu off Home no longer collapses and re-expands as the pointer moves over it on macOS through Screen Sharing. It now collapses only after the pointer has been off it for a quarter of a second.
