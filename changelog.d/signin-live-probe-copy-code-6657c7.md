### Added

- The Quick Connect code on the sign-in screen has a copy button, so you can paste the code into another Jellyfin client.

### Changed

- The sign-in screen checks whether your server supports Quick Connect while you type the server address. You no longer have to click out of the Server field before Use Quick Connect becomes available. An address without a domain ending or port, such as a plain LAN hostname, is still checked when you leave the field.
