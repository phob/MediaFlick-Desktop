# 0011. Jellyfin client accommodates server version floors, header-only auth, and API quirks

Status: Accepted (2026-11-22). Consolidated from codebase audit of `src/jellyfin/`, `src/library/`, `src/shell/cef/api/`, and `ui/src/lib/`.

## Context

MediaFlick Desktop supports Jellyfin 10.11.0 and newer (`DESKTOP_MINIMUM`), while the Companion builds against Jellyfin 12.0.0 (`MINIMUM_SERVER`). Real Jellyfin servers exhibit undocumented behaviors during startup migrations, pagination, metadata encoding, image delivery, and push updates that break naive REST clients.

## Decision

- **Version floor and startup detection.** `ServerVersion` parses Jellyfin's `.NET` `Version.ToString(3)` strictly as three ASCII-digit parts (pre-checking `is_ascii_digit` because `u32::from_str` accepts `+`). All Jellyfin DTOs use `#[serde(default)]` without `deny_unknown_fields`, and `ServerVersion::deserialize_reported` maps unreadable versions to `Ok(None)` so `/System/Info/Public` still decodes. During startup migrations, Jellyfin's stand-in HTTP server answers HTTP 200 without `Version` (or briefly returns camelCase on 10.11.11) and 503 elsewhere; Desktop treats missing/camelCase versions as "server is starting up" rather than a permanent failure.
- **HTTP agents and header-only tokens.** Short-lived `JellyfinClient` structs share static `core` and `companion` `ureq::Agent` pools (kept completely free of server/account config) with `http_status_as_error(false)` so `Retry-After` headers on 429 and Companion error bodies stay readable. Access tokens never travel in URL query parameters (`TOKEN_QUERY_KEYS`): direct-stream URLs omit `api_key`, `TranscodingUrl` has embedded `ApiKey` stripped (relying on mpv forwarding `request.headers` to HLS playlists/segments), `/socket` authenticates via the `Authorization: MediaBrowser` header, and `get_bytes_range` proxies `<video>` `Range` requests natively. All artwork passes through Rust's image proxy (`src/shell/cef/api/images.rs`) forwarding `maxWidth` (preventing full-res decode stutter), using each image type's own tag and substituting `seriesId` for inherited `ParentBackdropImageTags` on seasons/episodes. `replace_cached` renames temp files without `fsync` because cached posters are disposable and `fsync` adds ~20 ms per poster on spinning disks.
- **Item eviction and playstate semantics.** A Jellyfin image 404 does not prove deletion, so `forget_if_server_disowns` probes `/Items?ids=` (`Ok(None)` evicts under the active account and triggers sync; `Err` preserves cache). After playback stops, Desktop flushes playstate and re-fetches the item so Jellyfin's server-side admin resume thresholds (default `MinResumePct` = 5%) decide Continue Watching membership. MediaFlick's "In progress" (`PlaybackPositionTicks > 0 && !Played`) intentionally differs from Jellyfin's `Filters=IsResumable`, which includes rewatches of played items.
- **Device profile, tracks, and remote control.** `DeviceProfile` declares unrestricted DirectPlay for Video/Audio and omits `TranscodingProfiles` unless capped quality is chosen. `TrackPreference` stores full stream descriptors alongside Jellyfin's absolute stream index to detect index reuse after file replacement, treating `None` saved fields as wildcards and comparing volatile localized `DisplayTitle` only when no stronger descriptor exists; `IsHearingImpaired` is preserved separately. `subtitle_stream_index = Some(-1)` distinguishes explicit subtitles-off from server default; positional `media_source_index` fallback is forbidden when a saved `media_source_id` vanished. On WebSocket connect, `/Sessions/Capabilities/Full` is posted on its own non-fatal thread with `SupportsMediaControl: true` (Playstate commands), `SupportedCommands` (GeneralCommand volume/mute only), and `SupportsPersistentIdentifier: false` (preventing stale cast targets); `ForceKeepAlive` is halved (`>= 5 s`) as the ping cadence, and `GeneralCommand.Arguments` accepts stringified numbers.
- **Observed Jellyfin API quirks.**
  - `ParentId` points to the immediate folder, not the top-level library, requiring `/Items?parentId=<lib>&Recursive=true`; Jellyfin ignores `SortBy=Id`, so walks sort by `DateCreated,SortName`.
  - `/Items/Latest` (`LiveLatest::Grouped`) is preferred for live libraries because newest-first `/Items` surfaces scan-timestamped folders/albums/series first; box sets and playlists return empty from `/Items/Latest` and use `LiveLatest::Newest`; `GroupItems=true` repurposes `ChildCount` to newly added count, so Desktop clears it.
  - Only `/Playlists/{id}/Items` preserves manual order; Jellyfin's `PlaylistItemId` equals the item's own ID, so Desktop synthesizes `playlist_index` for duplicate slots and uses `q{queue}-{ordinal}` in `NowPlayingQueue`.
  - `UserDataChanged` pushes climb only episode -> season (not series), so series `unplayed_count` is computed locally; `LocationType == "Virtual"` marks missing episodes; `Status` is always returned on series; `PremiereDate` provides a year fallback when `ProductionYear` is absent; TV networks live in `Studios`; Specials use season index 0 (moved to the end of season rails); cast `Person.Type` may be omitted when `role` is set; older `/Persons` responses may omit `Type`; `EnableImages=false` strips `People` headshots; `PersonIds` credits seasons/episodes too (requiring `IncludeItemTypes` filtering); Jellyfin truncates stored cast lists per title; `/Similar` mixes trailers/Live TV under `EnableExternalContentInSuggestions` (requiring 2x overfetch + kind filtering) and breaks score ties randomly; `MediaSourceInfo.Path` returns an opaque ID for non-admins (requiring a 1–5 char alphanumeric extension filter after stripping server directories); spatial audio uses `AudioSpatialFormat` on newer servers and `Profile`/`DisplayTitle` on older ones; DTS-HD arrives as `codec: "dts"` + `profile`; language fields may emit `"und"` or non-BCP-47 strings; episodes rarely carry logos (fetching parent series logo) and Series/Season containers have no `MediaStreams` (proxied via a representative cached episode); Quick Connect relies on server-side 404 expiry with no client deadline; server URL normalization treats `host:8096` as a port and inspects raw authority to avoid WHATWG shorthand IPv4 expansion (`192.168.1` -> `192.168.0.1`).

## Rejected alternatives

- Query-string `api_key` on stream, transcode, image, or WebSocket URLs: leaks credentials into process arguments, mpv logs, DOM attributes, and browser history.
- Trusting `MediaSourceInfo.Path` or `PlaylistItemId` verbatim: breaks non-admin UI display and duplicate playlist items.
- Strict `deny_unknown_fields` on Jellyfin DTOs: breaks sync whenever Jellyfin adds fields in point releases.

## Consequences

- Desktop must continue working without the Companion on Jellyfin 10.11 while gating Companion features on 12.0.
- Token-only `Authorization: MediaBrowser Token="..."` headers (without Client/Device/DeviceId) allow verification harnesses to query Jellyfin without mutating server device records.
- Media resolution labels and `videoQuality` weight width over height so 2.39:1 scope transfers (e.g. `1920x804`) classify accurately as `1080p`.
