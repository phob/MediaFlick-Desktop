# 0016. Release state machine, v0.1.6 migration, packaging, and isolated E2E verification

Status: Accepted (2026-11-22). Consolidated from codebase audit of `scripts/`, `distribution/`, `src/preferences/v0_1_6.rs`, `examples/verify-wm-close.rs`, and `.claude/skills/verify-mediaflick/`.

## Context

Shipping across Windows, Linux, and macOS involves an automated `release.toml` pipeline, carrying forward MediaFlick 0.1.6 user intent, reproducible cross-compiled runtimes, and headless E2E verification under Xvfb and Windows private desktops without leaking state into the developer's environment.

## Decision

- **Release channel state machine and CI guards.** Per operator rules (2026-11-15 / 2026-11-17 D6): every new version ships first as a published prerelease (at which point its `library.db` schema counts as released and must be frozen in `fixtures/library-db/released/`); a subsequent PR changing only `release.toml`'s `channel` to `"latest"` promotes it; versions are strictly monotonic and match `Cargo.toml`. `prepare-release.py --transition` diffs against `git merge-base` so older branches do not appear to downgrade Latest; `keep_desktop_latest.py` preserves older desktop tags marked Latest so manual rollbacks are not overwritten. `check_changelog_fragment.py` explicitly exempts `.csproj`, `.props`, and `packages.lock.json` because they live inside `plugin/` (unlike `Cargo.toml` and `ui/package.json`).
- **v0.1.6 read-only upgrade and `custom-art/` safety.** MediaFlick 0.1.6 stored device settings in `config.json` (written via `serde_json::to_vec_pretty`, no trailing newline, on clean CEF `window.close()`, omitting default `player_backend`) and keybindings in `input.json` (blank string = disabled). Newer builds import them read-only when `settings.json` is absent without modifying them, map `"mpchc"` explicitly to `Some(PlayerBackend::Libmpv)` (so a co-existing `mpv_path` does not override it, while unknown backends remain rejected), and use `config.json` presence to trigger the one-time What's new dialog. Extending [ADR 0005](0005-expand-only-persistence.md), orphaned `custom-art/` cleanup is skipped whenever any `collections.json.broken-*` file exists (PR #342) or `collections.json` is missing (2026-11-17).
- **Packaging and runtime builds.**
  - *Windows libmpv:* `distribution/libmpv/windows/build.sh` exports process-local `GIT_COMMITTER_NAME`/`EMAIL` for `git am` on clean CI runners and runs `ninja gcc` to completion before `ninja mpv` because `mpv-winbuild-cmake`'s dependency graph assumes the MinGW cross-compiler exists first.
  - *macOS DMG:* `distribution/macos/build-dmg.sh` constructs all five CEF helper `.app` bundles (`Helper`, GPU, Renderer, Plugin, Alerts) copying the main binary, locates CEF frameworks and `.pak`/`.dat`/`.bin` resources across both flattened and unflattened `cef-dll-sys` archive layouts, and runs deep ad-hoc `codesign --force --deep --sign -`.
- **Isolated E2E verification and website capture.**
  - *Linux isolation:* `isolate-linux.sh` isolates `XDG_RUNTIME_DIR` (reused as short `TMPDIR` so Chromium's `SingletonSocket` and mpv's ~55-byte IPC socket stay under Linux's 107-byte `sun_path` limit; `session.mjs` fails fast if `len(TMPDIR) + 56 > 107`), sets `GVFS_DISABLE_FUSE=1`, and lazily unmounts `xdg-document-portal`'s `$XDG_RUNTIME_DIR/doc` FUSE mount before `rm -rf`. Node runners resolve on child `exit` and destroy stdio streams instead of waiting for `close` because `dbus-run-session` daemons inherit pipes. Process matching checks `/proc/<pid>/exe` and `argv[0]` before `/proc/<pid>/stat` `comm` (kernel-truncated to 15 chars: `mediaflick-desk`). Packaged `MEDIAFLICK_DESKTOP_EXE` runs skip staged `build/libcef.so` `LD_PRELOAD`. `verify-wm-close` selects `SUBSTRUCTURE_NOTIFY` on root under window-manager-less Xvfb to observe `WM_CHANGE_STATE`; native CEF context menus under Xvfb do not grab Escape, so drives click outside to dismiss; hover tests drive real X11 `xdotool` because CDP Input bypasses native mouse handling; fullscreen external mpv freezes CDP mouse input under Xvfb, requiring `default_fullscreen: "windowed"`.
  - *Windows isolation:* MSIX-packaged executables under `\WindowsApps\` launch children outside the parent Job Object, so `isolate-windows.ps1` refuses MSIX hosts and `platform.mjs` pins MSI PowerShell 7; `mainWindowShown()` relies on `.NET Process.MainWindowHandle` filtering via `IsWindowVisible`; isolated profile clones omit `instance.json` for a distinct single-instance mutex; loopback HTTP test servers drain request `Content-Length` bodies before closing so Windows does not send TCP RST.
  - *CDP, proxy, SQLite, and media capture:* CDP's `Fetch` domain ignores `mediaflick-desktop://`, so harnesses wrap `window.fetch` via `Page.addScriptToEvaluateOnNewDocument` + `Runtime.addBinding`; Sonner pauses toast dismissal while hovered, so `harness.mjs` parks the pointer on toast hit; Node `http.request` decodes chunked bodies on refused Upgrade responses, so `proxy.mjs` strips `transfer-encoding` and writes `Connection: close`; live WAL inspection uses SQLite's online backup API (and `freeze_release.py` uses `?mode=ro&immutable=1` to avoid creating `-shm`, while scrubbing `rating_cache` vote counts to `1000` for privacy). Jellyfin E2E profiles live on disk (not tmpfs `/tmp`) for Jellyfin's 2 GiB free-space check, use `LibraryOptions.PathInfos` (Jellyfin 12 dropped the `paths` query param), and trigger `/Library/Refresh` after adding all folders; `/Sessions` remote commands filter by `SupportsMediaControl`. CEF tiles screenshots under CDP `setDeviceMetricsOverride` or `clip`/`scale`, so `capture.mjs` resizes the real DPI-aware (`SetProcessDPIAware` + `SW_RESTORE`) window iteratively, clamps Chrome full-page captures under 16,384 device px, duplicates the last frame in `ffconcat` (ffmpeg otherwise ignores its duration), and keeps fractional-DPI odd-height intermediates in `yuv444p` before final even-dimension `yuv420p` encodes. `test_prepare_release.py` registers dynamically imported modules in `sys.modules` before `exec_module` for `@dataclass` postponed annotations.

## Rejected alternatives

- Copying live `library.db` bytes directly or running Jellyfin E2E profiles in `/tmp`: produces torn WAL snapshots or fails Jellyfin's 2 GiB free-space check.
- Using CDP `Emulation.setDeviceMetricsOverride` or `clip` for website captures: produces tiled screenshots in CEF.
- Deleting `custom-art/` orphans when `collections.json` is missing or `.broken-*` exists: risks wiping user-uploaded posters after a parse error or file move.

## Consequences

- E2E harness scripts rely on these platform-specific isolation guards and should not be simplified by removing FUSE unmounts, `TMPDIR` length checks, MSIX refusals, or `window.fetch` wrappers without testing on the affected OS.
- Freezing fixtures from a real profile requires running `freeze_release.py` so tokens and uniquely identifying vote counts are never committed.
