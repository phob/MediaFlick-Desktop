Install the MediaFlick Companion.

The Companion is an optional Jellyfin plugin. It brings Sonarr, Radarr, Seerr, MDBList and TMDB into MediaFlick Desktop, and keeps their addresses and API keys on your server. A Jellyfin administrator installs it once for everyone.

Requires Jellyfin 12.0.0 or newer. Older servers don't offer the Companion in their catalog.

  1. 01

    Add the plugin repository

    In Jellyfin, open Dashboard → Plugins → Repositories, add a repository named MediaFlick Companion with this URL, and save.

    https://flick.media/companion/manifest.json
  2. 02

    Install MediaFlick Companion from the catalog

    Open Dashboard → Plugins → Catalog, find MediaFlick Companion under General, and install the newest version.

  3. 03

    Restart Jellyfin

    Jellyfin loads a new plugin when it starts. Restart it from the Dashboard, or restart its service or container.

Then

Open Dashboard → Plugins → MediaFlick Companion to connect Seerr, Sonarr, Radarr, MDBList and TMDB. Each is optional. In MediaFlick Desktop, Settings → MediaFlick Companion shows the plugin and which features it offers. Updates arrive through the same repository.

The administrator guide covers each service, the shared rating quota and what Desktop can see.
