Install the MediaFlick Companion.

The Companion is an optional Jellyfin server plugin. A server admin sets it up once to connect Seerr, Sonarr, Radarr, MDBList, and TMDB — and every MediaFlick Desktop user on the server gets those features without ever seeing an API key or internal service address.

Requires Jellyfin 12.0.0 or newer. Older servers won't list the Companion in their plugin catalog (MediaFlick Desktop still works fully on Jellyfin 10.11+ without it).

Stays on your server

  • Encrypted provider credentials (ASP.NET Data Protection)
  • Internal URLs for Seerr, Sonarr, Radarr, MDBList, and TMDB
  • Shared, quota-aware MDBList rating cache across all users
  • Typed, Jellyfin-authenticated endpoints — no generic proxy

Unlocks in MediaFlick Desktop

  • Live Sonarr & Radarr status on Requests and the Home Timeline
  • Seerr Discover, movie requests, and missing-season requests
  • TMDB movie franchises split into owned and missing
  • Up to twelve rating sources on cards, previews, and details
  1. 01

    Add the plugin repository

    In Jellyfin, go to Dashboard → Plugins → Repositories, add a repository named MediaFlick Companion with this URL, and save.

    https://flick.media/companion/manifest.json
  2. 02

    Install MediaFlick Companion from the catalog

    Open Dashboard → Plugins → Catalog, pick MediaFlick Companion under General, and install the latest version.

  3. 03

    Restart Jellyfin

    Jellyfin loads newly installed plugins on startup. Restart from the Dashboard, or restart the Jellyfin service or container.

Configure only what you run

Open Dashboard → Plugins → MediaFlick Companion to hook up Seerr, Sonarr, Radarr, MDBList, or TMDB — every integration is optional and has its own connection test. MediaFlick Desktop discovers the plugin automatically and reports which features are active under Settings → MediaFlick Companion. Future plugin updates arrive through the same repository.

See the administrator guide for credential storage, Seerr user mapping, and MDBList quota details.
