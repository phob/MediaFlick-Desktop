01

Why external mpv?

An embedded player is convenient. It is also not your player.

People who tune mpv tend to depend on the parts around it: SVP4, SDR-to-HDR conversion, custom shaders, Lua scripts and precise input bindings. MediaFlick does not try to reproduce that setup inside a web view. It launches the executable you already use.

~/.config/mpv/mpv.confunchanged
profile=gpu-hq
vo=gpu-next
glsl-shaders-append="~~/shaders/FSRCNNX_x2.glsl"
input-conf="~~/input.conf"
02

What the app handles

Library

MediaFlick mirrors titles, summaries, genres and cast into SQLite. Search runs against that local index instead of waiting on a server request for every keystroke.

Background sync · Full-text search

Playback

Original-quality streams go straight to mpv. For slower links, choose Jellyfin's automatic limit or set a bitrate from 1.5 to 120 Mbps.

mpv · MPC-HC on Windows · Track selection

Playstate

The app sends playback start, progress, watched status and resume position to Jellyfin. Finishing a film in mpv updates the server for your other devices.

Progress reports · Resume points

Library extras

Browse a release calendar and collections in the desktop app. The optional server companion adds Seerr requests, external ratings and richer collection data without sharing service keys with clients.

Optional companion plugin
