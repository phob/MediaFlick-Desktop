02 · Companion

One server plugin. Zero keys on clients.

The optional MediaFlick Companion installs inside Jellyfin 12.0+ and talks to Sonarr, Radarr, Seerr, MDBList, and TMDB on the server's behalf. Desktop only calls typed, Jellyfin-authenticated endpoints — there is no generic proxy, and service URLs and API keys never leave your server.

Requires Jellyfin 12.0.0+. Every service is optional, Seerr calls run as the mapped Jellyfin user, and MDBList uses one shared, quota-aware cache. On Jellyfin 10.11, Desktop still runs in full without the plugin.

04 · Playback

It's mpv either way.

Most people want playback to just work on first launch — so Windows releases and the Linux AppImage bundle libmpv right inside the app window. Already spent years dialing in shaders, HDR profiles, and mpv.conf? Flip one toggle to hand off to your own external mpv.

Win · libmpv + SVP 4 Linux · Vulkan + NVDEC macOS alpha · External mpv
  • Zero setup on Windows and Linux. Windows releases and the Linux AppImage ship a bundled libmpv runtime — nothing extra to install.
  • Native GPU rendering in one window. DirectComposition on Windows with automatic SVP 4 hooking; Vulkan (gpu-next) and hardware decoding (NVDEC / auto-safe) with OpenGL fallback on Linux X11 or XWayland.
  • Controls made for your setup. MediaFlick's overlay sits over native video with live subtitle styling preview, recordable keyboard shortcuts, and TV remote support.
  • Original quality by default. Keep direct play, switch per-session right beside the Play button, or cap bitrate from 1.5 to 120 Mbps with Jellyfin transcoding.
~/.config/mpv/mpv.confUnchanged
profile=gpu-hq
vo=gpu-next
glsl-shaders-append="~~/shaders/FSRCNNX_x2.glsl"
target-colorspace-hint=yes
input-conf="~~/input.conf"
script-opts-append=svp-enabled=yes
  • Your config stays untouched. SVP 4, GLSL upscalers, Lua scripts, HDR tone-mapping profiles, and input.conf bindings run just like launching mpv yourself.
  • Full Jellyfin sync over persistent IPC. Start, progress, watched state, resume seek, segment skipping, and tokens in auth headers (never stream URLs) all work in external mode.
  • No manual hunting for binaries. Windows offers one-click mpv download in Settings; Linux and macOS auto-detect your system mpv.

06 · Playstate

Jellyfin never loses your place.

Stepping outside the browser usually breaks watched state or snaps resume points back to zero. Both players use one shared IPC reporter that seeks after file load, holds Jellyfin's saved timestamp until the seek settles, and syncs continuously.
